# Slay With Ray — Project Guidelines

This repository contains the web application for Slay With Ray (Raynisha Nicole).

## Features
- Custom Instagram Profile Badge & Iframe Feed integration for [@raynishanicole](https://www.instagram.com/raynishanicole/)
- 1:1 Fitness Coaching Applications & Calendly Booking
- Responsive UI built with TanStack Start, React & Tailwind CSS
- Production ready for Cloudflare Pages / Workers hosting
